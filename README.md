# 산재원샷 프로젝트 소개

산업재해 신청에 필요한 사실과 증빙을 단계별로 정리하고, OCR과 생성형 AI를 활용해 제출 준비를 돕는 **산재원샷** 프로젝트의 공개 소개 페이지입니다.

## 페이지 보기

<https://kimchaejun.github.io/Sanjae-Oneshot-Page/>

## 소개 내용

- 프로젝트 문제 정의와 핵심 가치
- 8단계 산업재해 신청 준비 흐름
- OCR 기반 증빙 확인과 AI 사고경위서 검토
- 한국어·영어·베트남어·필리핀어 UI
- 노인친화형 UI와 접근성 설계
- 시스템 아키텍처와 개인정보 보호 원칙

> 산재원샷은 근로복지공단의 공식 서비스가 아니며, 법률 판단이나 산재 승인 가능성을 제공하지 않습니다.

## 배포

`main` 브랜치의 `docs/`가 변경되면 GitHub Actions가 GitHub Pages에 자동 배포합니다.
