TIME MODEL

“얼마나 걸리나요?”를
두 개의 시간으로 답합니다.

사용자가 직접 조작하는 시간과 외부 기관의 서류 준비 시간을 분리해 안내합니다. 기다리는 시간을 숨기지 않되, 그동안 사용자가 반복해서 확인할 필요는 없게 설계합니다.

사용자 직접 조작 약 12분
5분정보 확인 2분AI 결과 확인 5분최종 검토
외부 서류 준비기관별 별도 안내
즉시기본 자격·사업장 정보 당일~1일전산 확인 가능 자료 1~3일+의료·추가 확인 자료

위 기간은 발표용 설계 가정이며 실제 기관 처리기한이 아닙니다. 운영 전 기관별 SLA를 연동해 실시간 예상일로 교체합니다.

DESIGN PRINCIPLES

자동화되어도 바뀌지 않는 원칙

01

동의한 정보만 요청

기관·문서·사용 목적을 먼저 보여주고 사용자가 허용한 범위만 요청합니다.

02

사실만 자동 작성

받은 문서와 입력값에 없는 날짜·수치·상황은 AI가 새로 만들지 않습니다.

03

제출 전 사람의 확인

자동 생성 결과는 초안이며, 마지막 사실 확인과 제출 결정은 신청인이 합니다.
